# Carpeta de Clases

En esta carpeta podrás encontrar Notebooks y archivos en general que te serán útiles para tu aprendizaje, algunos de estos están elaborados por gente externa a nuestra universidad y están acreditados en sus respectivas carpetas, por favor visita también su trabajo original.

## ¿Cómo usar esta carpeta?

Si eres alumno notarás que no puedes guardar modificaciones a los archivos, esto es porque esta carpeta se monta como **Solo Lectura**, es muy **IMPORTANTE** que si quieres trabajar sobre ellos, primero los copies a tu carpeta raíz.

Si eres profesor, crea una carpeta con el nombre de tu clase y añade los archivos que necesites (excepto bases de datos pesados, esos puedes agregarlo a la carpeta dedicada para esto).
